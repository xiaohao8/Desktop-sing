### 1.1 打磨轮 4：包与技术合规实测
- **核实 exe 内嵌 manifest**（用 WSDK mt.exe 导出）：`asInvoker + uiAccess="false"`，
  完全符合 MSIX 要求（requireAdministrator/uiAccess=true 会被拒）。
- **包内容清点**：229 文件 = 1 exe + 72 dll + 59 pyd + 91 assets，**无日志/pyc/
  卸载脚本残留**；MiSans-Regular.ttf 在 `_internal/fonts/`（英文 Windows 无中文字体
  也能正常显示）。
- **修真实健壮性缺陷（本轮最有价值的发现）**：`_start_fetch` 的 worker 闭包
  原先不兜 `fetch_lyrics` 的预期外异常 → 线程静默死亡 → `fetched` 信号永不发出
  → UI 永远停在「等待播放…」且无任何提示。审核断网/国内接口在海外超时极易触发，
  直接违反 10.3 可测试性。**修复**：worker 内 try/except + 无论成败都 emit，
  让界面走到「纯音乐或暂无歌词」降级显示。
- **新增 `store/render_shots.py`**：offscreen 真实渲染浮层（idle/hero）与设置面板，
  产出 1600×900 商店截图基线素材到 `store/out/shots/`。
  **要点**：① 必须 `widget.grab()`（render() 在本环境采出全透明）；
  ② 抓前要先 show() + 多轮 processEvents（否则设置面板抓到纯背景）。
- **离屏字体真相**：本沙箱 QFontDatabase 家族数=0，画什么都是豆腐块（含汉字）；
  应用内 `_load_fonts()` 显式加载内置 MiSans 后汉字正常，但 ♪(U+266A)/♫(U+266B)
  MiSans 没有字形 → 离屏显示豆腐块。**真实 Windows 上 Qt/DirectWrite 有系统级
  字体回退**（回退到雅黑/Segoe UI Symbol），用户真机从未反馈豆腐块，不用改代码。

### 2.6 打包踩坑（重要，下次别重复）

`build_store.py --fresh` 里 `subprocess.run(..., cwd=ROOT)` 调 `build_exe.py --dir`，
**返回码 0 但产物没更新**（时间戳不变、字节码里还是旧串）。直接手动跑
`.buildenv/Scripts/python.exe -u build_exe.py --dir`（输出重定向到文件再看）就正常了。
**判定产物是否真更新，只看 exe 的 mtime + size**，`wc -l` 看日志行数（正常约 110 行）；
不要相信 `--fresh` 的退出码。核验新代码是否入包仍用 `CArchiveReader` +
递归 `co_consts`/`co_names` 双查（**字符串常量查 co_consts，函数/全局名查 co_names**）。
