## 3. 审核员深度复查（第 3 轮）——「细节做到无可挑剔」

### 3.1 清单 Description 藏着第三方商标（政策 10.1.1 / 11.2）

**最严重的发现，也最容易被忽略**：`store/build_store.py` 的 `DESCRIPTION` 常量里写着
「…自动跟随**接入 SMTC 的播放器（如 QQ音乐 / 网易云音乐 / 酷狗音乐）**显示逐字歌词」。
这一串会被写进包元数据 `uap:VisualElements/@Description`，**商店页面直接可见**。

前两轮的去商标工作只覆盖了 `lyrics_overlay.py`、官网、README，**漏了打包脚本**——
说明「商标审查」不能只扫界面文案，必须枚举**所有用户可见载体**。

修法：删掉播放器品牌举例，改为只描述**客观兼容性事实**（「接入 Windows 系统媒体控制
（SMTC）的播放器」）——说明兼容性是合理使用，点名品牌才是风险。

**固化为检查**：P5.1 从「只扫 lyrics_overlay.py」扩展为多载体扫描：
P5.1b 清单 Description 商标扫描、P5.1c 播放器品牌黑名单、P5.1d 更新菜单文案如实性。

### 3.2 许可文件未随包分发（政策 11.2 第三方权利，**实打实的合规缺口**）

程序内置 MiSans 字体、歌词引擎借鉴 Apache-2.0 的 Lyricify-Lyrics-Helper，但
**三条分发渠道（MSIX / 便携 zip / NSIS 安装包）都没带任何许可或 NOTICE 文件**。

- Apache-2.0 第 4 条明确要求「向接收者提供一份 NOTICE」；
- 商店用户**只拿到 .msix，看不到 GitHub 仓库** → 只放仓库不满足要求；
- 内置 MiSans 亦要求保留许可说明。

修法：
1. 新建 `LICENSE-THIRD-PARTY.txt`（5 节：Lyricify 归属声明 + FluentFlyout「未使用源码」
   声明 + 内置/可下载字体 + 运行时依赖 + 歌词内容版权）。
2. 三条渠道全部随包：`build_store.py` 加 `BUNDLED_LICENSES` 常量并在 `stage_layout()` 复制
   （**文件缺失直接 SystemExit，不许静默跳过**）；`pkg_portable.py` 的 `docs` 列表加入；
   `installer.nsi` 加 `File /oname=第三方许可.txt`。
3. 「关于」窗口指引从「详见 NOTICE.md」改为「详见安装目录下的 LICENSE-THIRD-PARTY.txt」——
   商店用户看不到仓库，指向仓库文档等于没有。

### 3.3 商店版「检查更新…」文案误导（政策 10.1.1 准确描述）

代码行为本身正确（STORE_MODE 下手动点会提示「请在商店『库 → 获取更新』里升级」），
但菜单项文案和桌面版一样写「检查更新…」→ 用户以为应用内有更新通道，点了拿不到版本信息，
看起来像功能坏了。改为 `"在商店中获取更新…" if STORE_MODE else "检查更新…"`。

**教训**：行为正确 ≠ 描述正确。审核员读的是文案，不是源码。

### 3.4 缓存占用量显示「0.0 MB」像 bug

有 6 首缓存但总字节不足 100KB 时，`"%.1f MB"` 显示成 `0.0 MB`。审核员/用户会当成 bug。
改为 `total < 100*1024` 时用整数 KB（`15 KB`），否则 MB。

### 3.5 商店截图不达标（尺寸 + 可识别性 + 空白三重问题）

  → 重命名为 `store-shot-1-idle.png` 等。

- `composite()` 增加 `pixmap=` 参数，支持先 `grab()` 再算居中位置。

## 4. 审核员深度复查（第 4 轮）——多显示器 / 卸载残留 / 隐私披露一致性

### 4.1 多显示器写死主屏（真实功能 bug，两处）

**① `_preset_point()`**：用 `QApplication.primaryScreen().availableGeometry()` 算预设坐标。
- 症状：副屏用户点「贴底 / 居中 / 右上」等预设，窗口被 `move` **回主屏**（"自己跳回主屏"）。
- 连带：`_current_position_key()` 也按主屏坐标反查，副屏上的位置**恒判为 free**
  → 位置语义（预设 vs 自由）存不住。
- 修：`scr = self.screen()`，取不到再 `screenAt(QCursor.pos())` → 再退主屏
  （窗口未 `show()` 时 `self.screen()` 可能是 None）。

**② `AmbientSaver.start()`**：用 `primaryScreen().geometry().center()` 选屏。
- 症状：副屏用户触发屏保，**黑的是主屏**、副屏毫无动静 —— 像功能没生效。
- 修：跟随歌词条所在屏（`self.ov.screen()`），取不到退鼠标屏、再退主屏。

**关键：`_clamp_into_screen()` 一直用的是 `self.screen()`（正确）**，
说明代码里已经是两种写法混用 —— 这类「同一意图两种写法」的地方最容易出 bug，
以后新写定位型代码一律先问「该跟窗口还是跟主屏」。

实测方法：offscreen 只有一块屏，**无法直接构造双屏**；
改用「代码扫描 + 调用点追踪 + 往返一致性验证」：
- 套用每个预设 → `move` → 反查 key，7 个预设全部往返一致（`bottom` 首次 FAIL
  是测试假象：窗口 900 宽 > 屏 800 被夹取，改用 600 宽后全过）。
- 屏保 `start()` 实测 geometry == 歌词条所在屏 geometry。

### 4.2 NSIS 卸载残留（政策 10.2.7 / 用户体验）

### 6.2 ★ 核对素材时发现：三张商店截图里有两张是废图

**这是本轮最有价值的发现 —— 素材文件都在、大小也正常，但内容不对，纯靠肉眼看不出来。**

|---|---|

**根因 ①（settings 空白）：offscreen 下淡入动画不推进。**
`SettingsPanel.showEvent()` 里起了一个 180ms 淡入（`QVariantAnimation` 0→1 驱动
`QGraphicsOpacityEffect.setOpacity`）。offscreen 下没有真实 event loop、时间也不流逝，
动画停在 `opacity=0.0` → `grab()` 返回**非 null 但全透明**的图。
**`isNull()` 判不出来 → 空白图静默落盘。** 修：`_fade.stop()` + `_fx.setOpacity(1.0)`。

**根因 ②（hero 缺歌词）：三处都踩了。**
- 绘制读的是**缓存文本** `self._current_text`（由 `_tick()` 从 `lines` 推出），

  —— 上一版正是因此显示的是 `_idle_current_text()` 回退文案
  （「♪ 歌名 · 歌手」，所以图里只有歌名）；

  `_current_pos() = time.monotonic() - 0.0` = **开机以来的秒数** → 时间轴飞到天外、行号全乱；
- 切行动画把 `_line_t` 停在 0，`_apply_line_anim()` 里
  `p.setOpacity(p.opacity() * _smoothstep(0))` → **整行 opacity 乘成 0**。

**解法：直接照抄 `lyrics_overlay.py` 里既有的绘制自检写法**（约 7462 行）——
它早就把「喂 `_current_text`/`_next_text`、设 `cur_idx`、推 `_line_t`、
设 `anchor_pos`+`anchor_ts`、`_relayout()`」这套摆对了。**先找代码里已有的同类用法，
别自己猜怎么构造。**

另外改成「**先 grab 再按实际尺寸居中**」：`_relayout()` 可能把窗口自适应成别的尺寸，
写死坐标会让浮层偏出画面（实测窗口 1000×320 而 pill 只有 394×136）。

### 7.2 怎么在没有 gh CLI 的情况下上传

## 12. 「线上还是旧图标」——其实是缓存，不是没部署

用户报 `https://music.202271.xyz/assets/icon-180.png` 仍是旧图标。

**第一反应别急着重新部署，先核对线上文件本身**：
```
curl -s -o live.png "https://music.202271.xyz/assets/icon-180.png?cb=$$"
```

  资源一变指纹就变、URL 就变 → 缓存自然失效；没变则指纹不变 → 缓存照旧有效。
  实测指纹 `a4bfa1c4cb`，index.html 19 处引用全部打上。
- `netlify.toml`（**只在部署仓库里**）改注释写清前提，另把隐私页规则
  `/privacy*.html` → `/privacy*`（Netlify 会把 `/privacy.html` 改写成无扩展名的

- `store/audit_round3.py` 新增 **P5.21 两项**：三页 assets 引用必须带 `?v=`，
  且指纹要与 `site/assets/` 实际内容对得上（防「改了资产没重跑 make_assets.py」）。

```python
h   = sha256(publisher.encode("utf-16-le")).digest()[:8]   # 取前 64 位

ALPHA = "0123456789abcdefghjkmnpqrstvwxyz"                 # 去掉易混 i/l/o/u
hash13 = "".join(ALPHA[(big >> (5*(12-i))) & 31] for i in range(13))
```

**`<< 1` 那一步不能省**：13 字符 × 5 bit = 65 bit，少补这一位最后一字符必然错
