桌面歌词 —— 使用说明
================================

【快速上手】
1. 双击 Desktop-sing.exe 启动（安装版可从桌面/开始菜单的「桌面歌词」进入）；
   普通启动会打开播放器主窗口：左侧为最近播放与功能导航，右侧为全屏歌词舞台；
   标题栏「迷你模式」可切回桌面歌词条。登录自启只显示迷你歌词条。
2. 用 QQ音乐 / 网易云音乐 / 酷狗音乐（或任意接入 Windows 系统媒体栏的播放器）
   播放歌曲，桌面会自动出现歌词悬浮条；
3. 鼠标悬停在悬浮条上会弹出控制条：上一首 / 播放暂停 / 下一首 / 屏保 / 锁定 / 设置；
4. 右键悬浮条或托盘图标可换悬浮样式与配色主题、调字号、开翻译；
   托盘菜单「配色主题」有 14 款精选配色，默认跟随专辑封面主色自动换肤。

【常见问题】
· 安装时提示「D 盘没有写入权限」？—— 安装程序会自动改到用户目录
  （C:\Users\<你的用户名>\AppData\Local\Desktop-sing）；想装到别处，可在
  「安装目录」那一步自己选一个有写入权限的位置。
· 免安装版解压到哪里？—— 解压到你有写入权限的位置（例如桌面、
  C:\Users\<你的用户名>\Desktop-sing）；解压到无写入权限的盘会无法启动。
· 没有歌词？—— 歌词来自 QQ音乐/网易云/酷狗/LRCLIB 公开接口，纯音乐或冷门歌
  可能没有；可右键「重新获取歌词」再试一次。
· 想换字体？—— 设置面板 → 字体库，可一键下载 MiSans 等字体（下到本机
  %APPDATA%\Desktop-sing\，不上传任何数据）。
· 想听歌报告？—— 播放器左侧「听歌报告」查看本月 / 今日时长、连续听歌、
  活跃天数、最爱时段、常听歌手与热门歌曲；「播放历史」可按歌曲查看缓存歌词。
  单次不足 20 秒不记录，数据只在本机，可在设置关闭或一键清空。
· 歌词进度明显对不上、拖进度条后也回不来？—— 右键悬浮条 →「从 QQ 音乐校准进度」
  （就在「重新获取歌词」旁边）：程序只读一次 QQ 音乐窗口里显示的进度时间，确认后
  把歌词基准对齐过去。全程不点击、不激活 QQ 音乐，读不到就什么都不改；
  QQ 音乐收进托盘时窗口不可读，先点开主窗口再校准即可。
· 想换配色？—— 托盘图标右键 →「配色主题」14 款一键换肤；悬浮条、氛围光晕、
  屏保与设置面板的配色会一起变。也可以在设置面板 → 配色主题里选「封面取色」
  （默认，跟随每首歌的封面主色）或「固定主题」。
· 开机自启？—— 设置面板内可开关。
· 启动时卡住 / 想确认不是假包？—— 见下方「安全与放行」。

【数据位置】
· 配置/缓存/字体/听歌统计：%APPDATA%\Desktop-sing\
· 全部数据只存在你的电脑上，卸载即删（配置目录可手动删除）。

【卸载】
· 安装版：控制面板「卸载程序」或开始菜单「桌面歌词 → 卸载桌面歌词」；
· 免安装版 / 绿色版：直接运行程序目录里的「卸载桌面歌词.bat」即可
  （会自动关闭程序、删除配置目录与整个程序目录，无需安装器）。

【获取新版本】
· 程序内不检查更新，也不会后台请求版本清单；
· Microsoft Store 版：在商店「库」中获取更新，或等待商店自动更新；
· GitHub / 便携版：请从原发布页下载新版本，覆盖安装或完整解压后运行。

【安全与放行】
· 本程序暂无代码签名证书，Windows 首次运行可能弹出蓝色提示
  「Windows 已保护你的电脑」——点【更多信息】→【仍要运行】即可，只提示一次;
· Edge / Chrome 若提示有危险，在下载栏点【…→ 保留】；被自动删除则到
  下载列表里恢复;
· 个别杀毒软件会启发式误报（无签名的 PyInstaller 程序较常见），
  把整个程序目录加入信任 / 白名单即可;
  火绒与 Windows Defender 是两套独立引擎：Defender 的排除命令对火绒无效，
  需在火绒「信任区」里加目录或按进程信任 Desktop-sing.exe;
  商店版若被火绒删掉主程序，加信任后走
  「设置 → 应用 → 桌面歌词 → 高级选项 → 修复」补回文件，
  不要手动往 WindowsApps 拷文件（会破坏包完整性）;
· 想确认文件没有被替换：在 Release 附件里找到 SHA256SUMS.txt，然后执行
    certutil -hashfile <文件名> SHA256
  比对哈希值一致即为原始构建产物;
· 本程序不收集任何信息（见隐私声明.txt）。
