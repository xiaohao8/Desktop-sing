桌面歌词 1.0 —— 使用说明
================================

【快速上手】
1. 双击 Desktop-sing.exe 启动（安装版可从桌面/开始菜单的「桌面歌词」进入）；
2. 用 QQ音乐 / 网易云音乐 / 酷狗音乐（或任意接入 Windows 系统媒体栏的播放器）
   播放歌曲，桌面会自动出现歌词悬浮条；
3. 鼠标悬停在悬浮条上会弹出控制条：上一首 / 播放暂停 / 下一首 / 屏保 / 锁定 / 设置；
4. 右键悬浮条或托盘图标可换主题、调字号、开翻译。

【常见问题】
· 安装时提示「D 盘没有写入权限」？—— 安装程序会自动改到用户目录
  （C:\Users\<你的用户名>\AppData\Local\Desktop-sing）；想装到别处，可在
  「安装目录」那一步自己选一个有写入权限的位置。
· 免安装版解压到哪里？—— 解压到你有写入权限的位置（例如桌面、
  C:\Users\<你的用户名>\Desktop-sing）；解压到无写入权限的盘会无法启动。
· 没有歌词？—— 歌词来自 QQ音乐/网易云/酷狗/LRCLIB 公开接口，纯音乐或冷门歌
  可能没有；可右键「手动搜索歌词」。
· 想换字体？—— 设置面板 → 字体库，可一键下载 MiSans 等字体（下到本机
  %APPDATA%\Desktop-sing\，不上传任何数据）。
· 开机自启？—— 设置面板内可开关。
· 被杀毒软件误报？—— 本软件无签名证书，个别杀软会对无签名的 PyInstaller
  程序启发式误报。请加入信任/白名单；本软件不收集任何信息（见隐私声明.txt）。

【数据位置】
· 配置/缓存/字体：%APPDATA%\Desktop-sing\
· 全部数据只存在你的电脑上，卸载即删（配置目录可手动删除）。

【卸载】
· 安装版：控制面板「卸载程序」或开始菜单「桌面歌词 → 卸载桌面歌词」；
· 免安装版 / 绿色版：直接运行程序目录里的「卸载桌面歌词.bat」即可
  （会自动关闭程序、删除配置目录与整个程序目录，无需安装器）。

【检查更新】
· 设置面板 → 系统 → 更新地址：填你的 GitHub Releases 链接
  （如 https://github.com/<你>/<仓库>/releases/latest）或一份「更新清单」JSON 链接；
· 清单 JSON 写法：{"version":"x.y.z","url":"下载链接","notes":"更新说明"}，
  url 可填蓝奏云等任意直链；
· 开启「启动自动检查」后，每次启动会自动比对版本，发现新版本会弹窗提示并给出下载入口；
· 也可随时右键托盘图标 → 系统 → 检查更新…，或设置面板里点「立即检查更新」。
