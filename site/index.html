常见问题

你可能想问。

需要先安装 Python 吗？
不需要。下载的是一个单文件 exe，双击直接运行，不依赖 Python 或任何运行库。
支持哪些播放器？
凡是接入 Windows 系统媒体控制（SMTC）的播放器都能读到，包括 QQ音乐、网易云音乐、酷狗音乐等。 同时开着多个播放器时，跟随正在播放的那一个。
没有代码签名，安全吗？首次运行被拦怎么办？
本程序还没配代码签名证书（按年付费），Windows 对「无签名 + 下载量还没攒起来」的新程序 会弹蓝色警示框，这是 SmartScreen 的默认策略，不代表文件有问题。 点【更多信息】→【仍要运行】即可，之后不再提示。 想确认下载的没被换包，可用 Release 附件里的 SHA256SUMS.txt 核对哈希。 程序本身不向任何服务器上传数据。
歌词对不上 / 匹配错了怎么办？
两种办法：① 右键菜单或托盘里的「重新获取歌词」，清掉该曲缓存后重抓； ② 用设置面板里的「歌词偏移」校准——歌词比歌声慢就点「提前」，快就点「延后」。
它会联网吗？会上传我的数据吗？
歌词从公开接口获取，所以取词时需要联网；除此之外不联网，也不会向任何服务器上传数据。 取到的歌词缓存在本地，下次播放同一首歌时秒开。
为什么歌词里有个别字显示不出来？
程序内置 MiSans 字体且不做子集化（子集化会让生僻字整个消失，比豆腐块更糟）。 若某些字仍缺失，可在设置面板的「字体库」里换一款字体，或下载一款覆盖更全的字体。
支持 macOS / Linux 吗？
目前只支持 Windows 10 / 11。核心依赖 Windows 系统媒体控制来获取播放信息。
