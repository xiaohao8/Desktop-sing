隐私政策

桌面歌词（Desktop-sing）是一款本地运行的桌面歌词工具。我们没有账户系统、 没有广告、没有统计埋点，也不收集能识别你身份的个人信息。

生效日期：2026 年 9 月 18 日 · 适用于桌面歌词 v1.0.0 及更高版本

1. 存储在本机的数据

所有设置、缓存与日志都保存在你电脑上的 %APPDATA%\Desktop-sing\ 目录，不上传到任何服务器：

文件 / 目录内容说明
config.json个人偏好设置样式、字号、快捷键、开关等
cache\歌词缓存按歌曲缓存已获取的歌词，避免重复请求
fonts\下载的字体文件从程序内置的字体库下载，免费商用字体
t2s.tsv繁简转换映射可选的用户自定义文件
desktop-lyrics.log运行日志排障用，只记录程序自身行为

删除方式：关闭程序后直接删除该目录即可。Microsoft Store 版本卸载应用时， 系统会一并清除包内数据。

2. 读取的系统信息（只在本机读取，不落盘、不上传）

本软件通过 Windows 提供的 系统媒体传输控制（SMTC，System Media Transport Controls） 读取当前正在播放的媒体信息，包括歌曲名、歌手名、播放进度与封面地址。 这是 Windows 自带的本地系统能力，任何接入 SMTC 的播放器都会对外提供这些信息。

说明几点边界：

  • 只读取「当前正在播放」的媒体信息，不读取你的音乐文件本身， 也不扫描磁盘上的音乐库；
  • 该信息仅用于在悬浮条上显示歌词、并据此去歌词接口查询对应歌词， 不会上传到我们的服务器（我们也没有服务器）；
  • 读取行为只发生在程序运行期间，退出程序即停止。

3. 发起网络请求的场景（仅功能所需）

程序在以下场景按需访问网络。请求内容只包含功能所必需的字段， 不包含你的姓名、联系方式、硬件指纹或任何账户信息（因为我们根本不采集它们）：

场景访问的服务发送的内容
获取歌词 QQ音乐、网易云音乐、酷狗音乐、LRCLIB 的公开歌词接口（多源并行、择优取用） 当前播放歌曲的标题、歌手、时长 / 歌曲 ID
显示封面 播放器提供的封面图片地址 仅下载该图片，不附带任何信息
下载字体 程序内置的字体发布渠道 仅下载所点的字体文件
检查更新
（仅非商店版）		 GitHub / Gitee / jsDelivr 的版本清单接口 仅比对版本号，不发送任何本地数据

Microsoft Store 版本没有「检查更新」行为——更新一律由商店分发。

关于请求头（如实说明）：部分音乐平台的公开接口只对常见客户端类型 返回结果，因此程序在请求这些接口时会带上通用的浏览器类型标识， 以及标注为「PC 端、客户端版本 2.9.7」的兼容性字段； 对 LRCLIB 与更新清单接口，程序使用自己的名称标识 Desktop-sing/1.0。这些标识仅用于让接口正常返回歌词数据， 不包含也无法包含你的任何个人信息，它们不与你的设备或账号绑定， 也不用于任何形式的身份识别或追踪。

歌词与封面均来自上述平台的公开接口，程序与这些平台之间不存在从属、 代理或合作关系。若你或平台方不希望此类请求发生，可在设置中关闭歌词获取， 或停止使用本程序。

4. 我们不做的事

  • 不收集个人身份信息、通讯录、文件、浏览记录；
  • 不上传你的任何本地数据（设置、日志、歌词缓存都只在本机）；
  • 不接入统计 / 埋点 SDK、广告 SDK 或第三方追踪服务；
  • 不出售或向任何第三方提供数据（没有数据可卖）；
  • 不申请摄像头、麦克风、位置等敏感权限。

5. 第三方服务

歌词与封面来自上述音乐平台的公开接口，字体与更新文件来自 GitHub / Gitee / jsDelivr / 蓝奏云等发布渠道。这些服务由各自的运营方控制， 可能有自己的隐私政策；本程序与它们之间只存在一次性的功能请求， 不向它们提供你的任何账户或设备信息。

6. 儿童

本程序不面向儿童，也不 knowingly 收集儿童的个人信息。它只是一款本地歌词显示工具。

7. 政策变更

若未来功能变化导致数据处理方式变化，我们会更新本页并更新顶部的生效日期。 历史版本可在 GitHub 仓库 查看。

8. 联系我们

对本政策或程序本身有疑问，欢迎到 GitHub Issues 提问，或在 Gitee 仓库 留言。
